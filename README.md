## ASIM
This archive contains all datasets and codes used in the manuscript. The structure has been organized to avoid confusion: each folder corresponds to a specific component of the study and contains its own README file with detailed instructions.

## Structure
-

 Contains the Python scripts used for analyses presented in the manuscript.  
 

- **Per-folder README files/**  
  Each folder includes its own README that explains in detail:
  - The purpose of the folder  
  - How to run the scripts  
  - Expected inputs and outputs  

## Usage
1. Extract the zip file.  
2. Navigate to the folder of interest (e.g., *Subsection 7.1 and 7.3 - BPLD Method with Examples*).  
3. Read the folder-specific README to see exact instructions.  
4. Run the scripts using Python (Google Colab or local environment with `pandas`, `numpy`, `matplotlib`, `scipy`).
